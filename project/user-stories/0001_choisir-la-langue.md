# Choisir la langue

En tant que maraîcher·e, je veux utiliser l'application dans ma langue.

- Je choisis entre Système, Français, English et Brezhoneg. Chaque langue est écrite dans sa propre langue, pour que je la reconnaisse même si l'application est dans une autre.
- Système suit la langue de mon ordinateur.
- Le changement s'applique tout de suite, sans rien enregistrer.
- Je retrouve ma langue à chaque lancement.
