# Renommer une ferme

En tant que maraîcher·e, je veux renommer une ferme, pour corriger son nom ou suivre ses changements.

- Je renomme la ferme ouverte.
- Le nouveau nom suit les mêmes règles qu'à la création : obligatoire, 255 caractères au plus, pas forcément unique.
- Le nouveau nom apparaît partout tout de suite.
