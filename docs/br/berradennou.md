# Berradennoù klavier

War macOS, an douchenn gemmañ pennañ eo ⌘ Cmd. War Windows ha Linux, Ctrl eo.

| Berradenn | Ober |

Bouton an atantoù a c'haller tizhout ivez gant an douchenn Tab, evel holl elfennoù an etrefas.
