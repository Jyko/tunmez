# Keyboard shortcuts

The primary modifier key is ⌘ Cmd on macOS and Ctrl on Windows and Linux.

| Shortcut | Action |
| --- | --- |
| Ctrl+O (⌘ Cmd+O) | Open the [farms](farms.md) page |

The farm button can also be reached with the Tab key, like every element of the interface.
