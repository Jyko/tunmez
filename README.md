# tunmez

Planificateur d'assolement pour fermes maraîchères.

tunmez aide les maraîcher·es à préparer leur saison de culture.

Gérez plusieurs fermes et passez de l'une à l'autre depuis la barre de l'application.

tunmez mémorise vos préférences d'affichage : langue, thème, contraste et fenêtre.
