# tunmez

Planificateur d'assolement pour exploitations maraîchères.

tunmez aide les maraîcher·es à préparer leur saison de culture.

Gérez plusieurs exploitations et passez de l'une à l'autre depuis la barre de l'application.

tunmez mémorise vos préférences d'affichage : langue, thème et fenêtre.
