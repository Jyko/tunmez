# tunmez

Steuñvaer tro-c'hounid evit an atantoù legumaj.

tunmez a skoazell al legumaerien hag al legumaerezed da brientiñ o c'houlzad gounid.

Merit meur a atant ha tremenit eus unan d'egile adalek barrenn an arload.

tunmez a zalc'h soñj eus ho kwellvezioù diskwel : yezh, tem, dargemm ha prenestr.
